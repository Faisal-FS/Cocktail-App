# 🍹 Cocktail App

An Android application built in **Kotlin** using **MVVM architecture** with the **Repository pattern**.  
The project follows a **Test-Driven Development (TDD)** approach to ensure clean, maintainable, and scalable code.  

This app was originally created as part of a **YouTube tutorial video**.  
It contains **two branches**:  
- **`base`** → Contains the starter/base code.  
- **`final`** → Contains the final working app.  

---

## 🚀 Features
- MVVM Architecture with Repository pattern
- Test-Driven Development (TDD) approach
- Dependency Injection with **Hilt**
- Network calls with **Retrofit2**
- Clean and scalable code structure

---

## 🛠️ Tech Stack
- **Language:** Kotlin  
- **Architecture:** MVVM + Repository  
- **Dependency Injection:** Hilt  
- **Networking:** Retrofit2  

---

## 📂 Branches
- `base` → Starter code for following along the tutorial  
- `final` → Complete working implementation
